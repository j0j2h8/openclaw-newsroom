# 투자 대가 토론 부서 설계

## 개요
세계적 투자 대가 7명의 시각으로 종목과 시장 이슈를 토론하는 부서.
의장(debate-moderator)이 주제에 맞는 3~4명을 선별 호출하여 토론을 진행한다.

## 의장 (debate-moderator)
- #ai-debate 채널에 바인딩
- 주제별 적합한 3~4명 선별 호출
- 토론 진행 및 최종 요약 게시

## 토론 트리거

| 트리거 | 내용 | 빈도 |
|--------|------|------|
| 추천 종목 검증 | 리서치부 추천 종목 발표 후 자동 토론 | 매일 (장마감/프리마켓) |
| 시장 이슈 토론 | 편집국장 지시 또는 속보 발생 시 | 수시 |
| 주간 시장 전망 | 다음 주 시장 방향 토론 | 매주 금 |

## 채널
- `#ai-debate`: 토론 결과 게시

## 토론 출력 형식

### 종목 검증
```
*투자 대가 종목 토론* | YYYY-MM-DD

*주제:* (종목명) 매수 적합성 검증
*패널:* (선별된 대가 3~4명)

*찬성*
• (대가명): (근거 2~3줄)

*반대*
• (대가명): (근거 2~3줄)

*결론:* 찬성 N / 반대 N — (의장 종합 코멘트)
```

### 시장 토론
```
*투자 대가 시장 토론* | YYYY-MM-DD

*주제:* (토론 주제)
*패널:* (선별된 대가 3~4명)

*라운드 1: 현황 진단*
• (대가명): (의견)
...

*라운드 2: 전망과 대응*
• (대가명): (의견)
...

*의장 종합:* (핵심 합의점과 분기점 정리)
```
