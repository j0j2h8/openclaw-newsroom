# 24시간 금융 편집국 설계

## 개요

OpenClaw 기반 24시간 자율 운영 금융 편집국. 투자 리서치, 속보 감지, 콘텐츠 제작, 리스크 관리를 부서 체계로 운영한다. 글로벌 시간대(아시아→유럽→미국)를 릴레이 커버하며, Slack 중심으로 발행하고 추후 외부 채널 확장 가능.

## 조직도

```
           ┌─────────────────────┐
           │   편집국장 (신규)     │  ← 전체 총괄, 부서간 조율
           │   #ai-desk      │
           └──────┬──────────────┘
                  │
     ┌────────────┼────────────┬──────────────┐
     ▼            ▼            ▼              ▼
┌─────────┐ ┌─────────┐ ┌──────────┐ ┌──────────┐
│ 리서치부  │ │ 속보부   │ │ 편집부    │ │ 리스크부  │
│ chief-  │ │ news-   │ │ editor-  │ │ risk-   │
│ analyst │ │  desk   │ │ in-chief │ │ manager │
│ #ai-research│ │ #ai-breaking│ │ #ai-editorial│ │ #ai-risk │
└─────────┘ └─────────┘ └──────────┘ └──────────┘
```

| 부서 | 부서장 | 채널 | 역할 |
|------|--------|------|------|
| 리서치부 | chief-analyst (기존) | #ai-research | 종목 추천, 시장 브리핑, 워치리스트, 기술/펀더멘탈 분석 |
| 속보부 | news-desk (신규) | #ai-breaking (신규) | 속보 감지, 긴급 알림, 글로벌 시간대 릴레이 모니터링 |
| 편집부 | editor-in-chief (기존) | #ai-editorial | 뉴스레터, 심층 분석, 섹터 리포트, 위클리 리뷰 |
| 리스크부 | risk-manager (기존→승격) | #ai-risk | 전 부서 공용 리스크 검증, 시장 위기 경보 |
| 편집국장 | newsroom-chief (신규) | #ai-desk (신규) | 부서간 조율, 일일 편집회의, 콘텐츠 캘린더 관리 |

## 속보부 (News Desk) — 신규

### 에이전트 구성

| Agent | 역할 | 출처 |
|-------|------|------|
| news-desk (부서장) | 속보 판단, 긴급도 분류, 알림 발송 | 신규 생성 |
| news-analyst | 뉴스 감성 분석, 영향도 평가 | chief-analyst에서 이관 |
| trend-researcher | 트렌드/바이럴 감지 | editor-in-chief에서 이관 |

### 운영 스케줄 (24시간 릴레이)

| KST 시간대 | 담당 세션 | 주요 감시 대상 |
|-----------|----------|--------------|
| 06:00~09:00 | 프리마켓 | 미국장 마감 여파, 유럽 선물, 환율 |
| 09:00~15:30 | 아시아장 | 코스피/코스닥, 아시아 주요 지수 |
| 15:30~22:30 | 장간 (유럽장) | 유럽 지수, 원자재, 글로벌 이벤트 |
| 22:30~06:00 | 미국장 | S&P/나스닥, FOMC, 실적 발표 |

### cron 스케줄

| 작업 | 주기 | 설명 |
|------|------|------|
| 속보 스캔 | 매 30분 | 웹 검색으로 금융 속보 감지 |
| 글로벌 세션 전환 알림 | 장 개장/마감 시 | 세션 전환 요약 |

### 속보 등급 체계

| 등급 | 기준 | 대응 |
|------|------|------|
| 긴급 (RED) | FOMC 금리 결정, 전쟁/제재, 서킷브레이커, 대형 실적 쇼크 | 즉시 #ai-breaking + 리서치부/리스크부에 분석 요청 |
| 중요 (YELLOW) | 주요 경제지표 발표, 대형주 실적, 섹터 급등락 | #ai-breaking에 요약 알림 |
| 참고 (GREEN) | 일반 시장 뉴스, 애널리스트 의견 변경 | 다음 정기 브리핑에 포함 |

## 리서치부 (Research Desk) — 기존 확장

### 에이전트 구성

| Agent | 역할 | 변경 |
|-------|------|------|
| chief-analyst (부서장) | 종합 분석, 추천 종목 최종 결정 | 기존 유지 |
| tech-analyst | 차트, 추세, 모멘텀 분석 | 기존 유지 |
| fundamental-analyst | PER, ROE, 재무제표 분석 | 기존 유지 |
| researcher | 종목 발굴, 공시 조사 | 기존 유지 |
| reporter | 리포트 작성, Slack 전달 | 기존 유지 |

news-analyst는 속보부로 이관. 리서치부에서 뉴스 분석이 필요하면 속보부에 요청한다.

### 기존 업무 유지

| 작업 | 스케줄 |
|------|--------|
| 미국장 마감 브리핑 | 평일 06:00 |
| 장 시작 전 브리핑 | 평일 08:30 |
| 장 마감 브리핑 | 평일 16:00 |
| 워치리스트 점검 | 장중 매시 |
| 내일의 추천 종목 | 평일 17:00 |
| 미국 추천 종목 | 화~토 06:30 |

### 신규 업무

| 작업 | 스케줄 | 설명 |
|------|--------|------|
| 섹터 로테이션 리포트 | 매주 금 17:30 | 주간 섹터 ETF 흐름 분석, 다음 주 유망/위험 섹터 제시 |
| 심층 종목 분석 | 매주 수 17:30 | 추천 종목 중 1개를 골라 기업 분석 딥다이브 |
| 속보 연동 분석 | 속보부 요청 시 | 긴급 속보 발생 시 영향 분석 |

## 편집부 (Editorial Desk) — 기존 확장

### 에이전트 구성

| Agent | 역할 | 변경 |
|-------|------|------|
| editor-in-chief (부서장) | 콘텐츠 기획, 최종 편집, 품질 관리 | 기존 유지 |
| content-writer | 본문 작성 | 기존 유지 |
| humanizer | AI 문체 제거, 인간화 | 기존 유지 |

trend-researcher는 속보부로 이관. 편집부에서 트렌드 조사가 필요하면 속보부에 요청한다.

### 콘텐츠 캘린더

| 콘텐츠 | 스케줄 | 소스 | 설명 |
|--------|--------|------|------|
| 데일리 뉴스레터 | 매일 04:00 작성, 08:00 게시 | 속보부 야간 스캔 + 자체 주제 선정 | 기존 유지 |
| 마켓 데일리 요약 | 평일 16:30 | 리서치부 장마감 브리핑 수신 → 편집 가공 | 리서치부 브리핑을 독자 친화적으로 재가공 |
| 섹터 위클리 | 매주 금 18:30 | 리서치부 섹터 리포트 수신 → 편집 | 섹터 로테이션 리포트를 뉴스레터 형태로 |
| 딥다이브 리포트 | 매주 수 18:30 | 리서치부 심층 분석 수신 → 편집 | 기업 분석을 읽기 좋은 장문 콘텐츠로 |
| 위클리 리뷰 | 매주 토 10:00 | 한 주간 추천 종목 성과 + 시장 요약 | 주간 성적표 |

### 편집 파이프라인

```
소스 입수 → editor-in-chief 기획/구성
         → content-writer 초안 작성
         → humanizer 문체 개선
         → editor-in-chief 최종 편집
         → #ai-editorial 게시 + 파일 저장
```

## 리스크부 (Risk Desk) — 승격 확장

### 에이전트 구성

| Agent | 역할 | 변경 |
|-------|------|------|
| risk-manager (부서장) | 리스크 평가, 시장 위기 경보, 포지션 검증 | sub-agent → 독립 부서장 승격 |

단독 부서로, sub-agent 없이 운영. 전 부서가 공용으로 호출하는 크로스 기능 부서.

### 업무

| 업무 | 트리거 | 설명 |
|------|--------|------|
| 추천 종목 리스크 검증 | 리서치부 요청 | 목표가/손절가 검증, 진입 차단 판단 |
| 속보 리스크 평가 | 속보부 긴급 시 | 긴급 이벤트가 포트폴리오/워치리스트에 미치는 리스크 평가 |
| 시장 위기 경보 | 자체 감지 (cron) | VIX 급등, 주요 지수 급락, 환율 급변 시 전 채널 경보 |
| 위클리 리스크 리뷰 | 매주 금 19:00 | 한 주간 리스크 이벤트 요약, 다음 주 리스크 캘린더 |

### 위기 경보 등급

| 등급 | 기준 | 대응 |
|------|------|------|
| RED | VIX 30+, 주요 지수 -3%+, 환율 +-2%+ | 전 채널 즉시 경보 + 리서치부 긴급 분석 |
| YELLOW | VIX 25+, 주요 지수 -1.5%+ | #ai-breaking에 주의 알림 |
| 정상 | 기준치 이내 | HEARTBEAT_OK |

## 편집국장 (Newsroom Chief) — 신규

### 에이전트 구성

| Agent | 역할 |
|-------|------|
| newsroom-chief (신규) | 전체 총괄, 부서간 조율, 일일 편집회의, 콘텐츠 캘린더 관리 |

편집국장은 직접 콘텐츠를 만들지 않는다. 조율과 감독만 한다.

### 업무

| 업무 | 스케줄 | 설명 |
|------|--------|------|
| 모닝 편집회의 | 매일 07:00 | 전일 실적 취합, 오늘 핵심 이슈/일정 정리, #ai-desk에 브리핑 게시 |
| 이브닝 마감회의 | 매일 19:00 | 당일 발행 콘텐츠 리뷰, 미발행 건 확인, 야간 커버리지 지시 |
| 위클리 성과 리뷰 | 매주 토 11:00 | 추천 종목 적중률, 속보 대응 속도, 콘텐츠 발행 건수 종합 평가 |
| 긴급 조율 | 속보부 RED 발생 시 | 리서치부/리스크부/편집부에 동시 지시 → 속보 대응 체계 가동 |

### 긴급 속보 조율 플로우

```
속보부: 긴급 속보 감지
  → 편집국장에게 보고
  → 편집국장이 동시 지시:
     ├→ 리서치부: 영향 분석 (워치리스트, 추천종목)
     ├→ 리스크부: 리스크 평가 (VIX, 포트폴리오 영향)
     └→ 편집부: 속보 콘텐츠 준비 대기
  → 분석 결과 취합
  → 편집부: 긴급 리포트 작성 → 발행
```

### 모닝 편집회의 출력 형식

```
*편집국 모닝 브리핑* (YYYY-MM-DD)

*오늘의 핵심 이슈*
- (이슈 1)
- (이슈 2)

*주요 일정*
- HH:MM — (이벤트)
- HH:MM — (이벤트)

*부서별 금일 업무*
- 리서치부: (오늘 예정 작업)
- 속보부: (주요 감시 대상)
- 편집부: (발행 예정 콘텐츠)
- 리스크부: (주요 리스크 이벤트)
```

### 부서간 통신 방식

편집국장이 각 부서에 지시할 때는 해당 부서장 에이전트를 sub-agent로 호출한다:
```
openclaw agent --agent <부서장-id> --session-id "$(uuidgen)" --message "<지시>" --thinking medium --timeout 600
```

## 구현 요약

### 신규 생성

| 항목 | 내용 |
|------|------|
| 에이전트 2개 | newsroom-chief (편집국장), news-desk (속보부장) |
| Slack 채널 3개 | #ai-desk (편집국), #ai-breaking (속보), #ai-risk (리스크) |
| Slack 채널 이름 변경 | #ai-picks → #ai-research, #ai-write → #ai-editorial |

### 기존 에이전트 변경

| 에이전트 | 변경 |
|---------|------|
| risk-manager | sub-agent → 독립 부서장 승격, cron 추가 (위기 스캔 매시) |
| news-analyst | chief-analyst 소속 → news-desk 소속으로 이관 |
| trend-researcher | editor-in-chief 소속 → news-desk 소속으로 이관 |

### 신규 cron 작업

| 작업 | 에이전트 | 주기 |
|------|---------|------|
| 속보 스캔 | news-desk | 매 30분 |
| 글로벌 세션 전환 알림 (4회) | news-desk | 06:00, 09:00, 15:30, 22:30 |
| 모닝 편집회의 | newsroom-chief | 매일 07:00 |
| 이브닝 마감회의 | newsroom-chief | 매일 19:00 |
| 마켓 데일리 요약 | editor-in-chief | 평일 16:30 |
| 섹터 위클리 | editor-in-chief | 금 18:30 |
| 딥다이브 리포트 | editor-in-chief | 수 18:30 |
| 위클리 리뷰 | editor-in-chief | 토 10:00 |
| 시장 위기 스캔 | risk-manager | 매시 정각 |
| 위클리 리스크 리뷰 | risk-manager | 금 19:00 |
| 위클리 성과 리뷰 | newsroom-chief | 토 11:00 |

### 총 cron 작업 수: 기존 9개 + 신규 11개 = 20개
